# proffy

女子大学生向けのプロフィール帳交換アプリです。
プロフィール帳を作成・交換することで、初対面でも共通点を見つけ、交流を深めることを目的としています。

---

## 機能

- ログイン
- 新規登録
- パスワード再設定
- 自己診断
- 診断結果表示
- プロフィール作成
- プロフィール交換

---

## 使用技術

- Vue 3
- JavaScript
- Vue Router
- Vite

---

## セットアップ

### パッケージのインストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

ブラウザで以下を開いてください。

```
http://localhost:5173
```
